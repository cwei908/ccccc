## 這是什麼

這裡收集我研究台股公司時寫的筆記。一家公司一頁，每一頁都用同樣的八個章節，這樣不同公司之間可以直接比較，過一季回來更新時也知道要改哪裡。

這些筆記是學習用的整理，不是投資建議，也不會出現「該不該買」這類結論。

## 每篇筆記的固定章節

| 章節 | 寫什麼 |
| --- | --- |
| 公司在做什麼 | 賣什麼、賣給誰、錢從哪裡賺 |
| 產業位置 | 在產業鏈的哪一段、地位、競爭者 |
| 近期營運重點 | 最近一季的成績和公司對未來的說法 |
| 關鍵數字 | 一張表，每個數字都有期間和來源 |
| 觀察與疑問 | 我自己的看法和還沒想通的問題 |
| 風險 | 至少三點 |
| 追蹤清單 | 下次更新時要確認的事 |
| 資料來源 | 編號清單，內文的小編號會連到這裡 |

只有「觀察與疑問」是觀點，其他章節只寫查得到出處的事實。

## 看數字的方式

- 數字後面的小編號可以點，會跳到頁尾的資料來源。
- 顏色照台股的習慣：**紅色是增加，綠色是減少**。
- 每篇頁首的四格數字，就是「關鍵數字」表的前四列。

## 這個網站怎麼做出來的

筆記本身是 Markdown 文字檔，放在 `content/notes/`。一支小程式會先檢查格式，再把文字檔轉成網頁。檢查的項目包括：章節順序對不對、每個數字有沒有來源、來源有沒有網址和日期、有沒有出現投資建議的用語。只要有一項沒過，網頁就不會產生。

所有規則都寫在專案的 [AGENTS.md](https://github.com/cwei908/ccccc/blob/main/AGENTS.md)。AI 讀完這份文件，就知道新增一篇筆記要放哪裡、怎麼命名、要寫哪些章節，以及完成前要跑哪些檢查。

## 新增一篇筆記的流程

1. 複製 `content/notes/_template.md`，改名成「股票代號-英文簡稱.md」。
2. 查資料、照章節填內容，每個數字標上來源編號。
3. 執行 `node scripts/build.mjs`，檢查通過後網頁和首頁列表會自動更新。

實際操作時，我只需要對 AI 說「依照 AGENTS.md 新增 2454 聯發科的筆記」，剩下的步驟它會照規則完成。
